# Next.js Blog Learning Platform

This is a demo blog application built with Next.js, designed as a learning resource for teaching modern web development concepts.

## Features

- **Next.js App Router**: Uses the latest routing features like nested layouts, server components, and route handlers.
- **TypeScript**: Full type safety for a better developer experience.
- **Tailwind CSS**: Utility-first CSS for rapid UI development.
- **Server Components**: Most of the app is rendered on the server for performance.
- **Client Components**: Interactive elements are built as client components.
- **Data Fetching**: Simulates an API with local JSON files.
- **Forms**: Uses `react-hook-form` and `zod` for form validation.
- **SEO**: Dynamic metadata generation for blog posts.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Contains all the routes, pages, and layouts.
- `components/`: Reusable React components.
- `lib/`: Helper functions, API logic, and validation schemas.
- `data/`: Mock data for the blog.
- `types/`: TypeScript type definitions.
